# 04_WEBSITE_DRAMATURGY

Status: Communication Architecture

Purpose:

This document defines the sequence through which visitors discover the work.

The website is not a brochure.

The website is a guided perception process.

---

# Core Principle

Order matters.

The same information presented in a different sequence creates a different experience.

Website dramaturgy is therefore the architecture of attention.

---

# Strategic Shift

Early versions attempted to explain the workshop.

Later versions revealed a more important insight:

People become interested when they recognize themselves.

Only afterwards do they become interested in the method.

---

# The Discovery Path

The ideal visitor journey:

1. Observation
2. Curiosity
3. Recognition
4. Credibility
5. Method
6. Application
7. Commitment

The website should support this progression.

---

# Observation Before Explanation

Strong opening questions:

- What happens between leading and following?
- Why is following often more difficult than leading?
- What happens when pressure increases?
- Why do skilled people suddenly lose access?

Questions create engagement.

Explanations come later.

---

# Leading And Following

Leading and following are not the destination.

They are the laboratory.

The website should repeatedly point toward the deeper subject:

Human navigation in relationship.

---

# Hidden In Plain Sight

One of the strongest dramaturgical themes.

Many workshop dynamics are already present in everyday life.

The workshop does not create them.

It makes them visible.

This creates curiosity without exaggeration.

---

# Facilitator Presentation

A major design decision:

Name
→ Positioning Sentence
→ Photo
→ Details

Not:

Name
→ Long Biography
→ Photo

Reason:

People orient visually before processing detailed information.

Trust is established faster through:

- face
- role
- credibility

before detailed credentials.

---

# Facilitator Function

The facilitators are not the hero.

The participant's discovery process is the hero.

Facilitator sections should therefore communicate:

- perspective
- competence
- observation capacity

rather than status.

---

# Credibility Sequence

Best order:

1. Observation
2. Practical examples
3. Facilitator credibility
4. Method explanation
5. Logistics

Many websites reverse this order and lose attention.

---

# Language Density

Complex ideas should emerge gradually.

Do not front-load terminology.

Introduce deeper concepts only after interest exists.

Examples:

Stage 1:
pressure, timing, trust, uncertainty

Stage 2:
relationship, coordination, perception

Stage 3:
human navigation, embodied process, resonance

---

# Visual Strategy

Images should support recognition.

Images should not dominate.

Photography functions primarily as:

- trust signal
- orientation cue
- human connection

not decoration.

---

# The Website's Real Job

The website does not need to convince everyone.

The website helps aligned people recognize:

"This is relevant for me."

That is enough.

---

# Future Evolution

As the project expands:

Workshop
→ Method
→ Community
→ Facilitator Pathway
→ Ecosystem

the website may evolve from event promotion to methodology platform.

This possibility should remain open.
