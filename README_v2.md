# Führen & Folgen Master Architecture

## Purpose

This repository contains the evolving methodology, communication framework, facilitator architecture, research layer, and long-term ecosystem design of Führen & Folgen.

The workshop is one expression of the work.

The methodology is deeper than the workshop.

The ecosystem is larger than the methodology.
